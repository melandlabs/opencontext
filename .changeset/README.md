# Changesets

Hello and welcome! This directory has been automatically generated by `@changesets/cli`.

## How do I use this?

When you make a change to any `@melandlabs/*` package, run:

```bash
pnpm changeset
```

You'll be prompted to:

1. Pick the affected packages
2. Choose the bump type (`patch` / `minor` / `major`)
3. Write a one-sentence summary for the changelog

This creates a Markdown file in `.changeset/` describing the change.
Commit it alongside your code change.

## What happens to my changeset?

- Every PR is checked: if `packages/*/src/**` changed but no changeset
  was added, CI fails (see `.github/workflows/ci.yml`).
- When the "Version Packages" PR is merged, all pending changesets
  are consumed, package versions are bumped, and CHANGELOGs are
  regenerated. That merge also publishes to npm via `pnpm release`.
